# Database

Tài liệu database đầy đủ (mô tả từng bảng, từng column, relationship, và lý do thiết kế) được đặt tại **[`../docs/database.md`](../docs/database.md)** để tránh có 2 bản tài liệu dễ bị lệch nhau khi cập nhật.

Thư mục này dự trữ cho các script hoặc tài liệu liên quan trực tiếp tới database mà không thuộc về Prisma (ví dụ: script backup, script import dữ liệu lớn ở giai đoạn sau) — hiện tại Phase 2 chưa cần.

Schema chính thức (nguồn sự thật duy nhất) nằm tại: [`../backend/prisma/schema.prisma`](../backend/prisma/schema.prisma)
